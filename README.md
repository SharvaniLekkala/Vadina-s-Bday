# Vadina's Birthday Surprise & Baby Girl Celebration 🎀👶🏻

A heartfelt, interactive, and aesthetic birthday surprise website created for my sweetest Vadina (sister-in-law).

This is a **Double Celebration**:
1. 🎂 **Her Birthday!**
2. 👶🏻 **The wonderful news that she is expecting a baby girl!**

## 🌸 Aesthetic & Design
- **Theme:** "A Birthday Full of Love & A Little Princess on the Way"
- **Color Palette:** Coquette pastel pink, blush pink, baby pink, cream, lavender mist, and champagne gold accents.
- **Typography:** Playfair Display, Cormorant Garamond, Poppins, and Dancing Script / Caveat handwriting styles.
- **Vector Artwork:** 100% handcrafted SVG illustrations (expectant mother with baby bump, teddy bears holding hearts, coquette bows, baby clothesline, booties, baby footprints, sleeping moon & stars).
- **Privacy First:** Clean digital scrapbook without any personal photographs or identifiable real pictures.

---

## 🎀 Key Interactive Features
1. **Interactive Opening Screen:** An animated 3D pink gift box with ribbon and bow that pops open with celebratory confetti and floating hearts upon clicking.
2. **Heartfelt Birthday Wishes:** Custom vintage lace card with personal wishes.
3. **Dedicated Mommy-to-be Section:** Celebrates the new little princess, featuring an interactive baby heartbeat pulse button.
4. **Interactive Pink Envelope & Letter:** Wax-sealed coquette envelope that smoothly opens and slides out a handwritten letter.
5. **Baby Princess Scene:** Clothesline with swaying baby outfits, cute teddy bear, sleeping moon, and a clickable pulsing heart revealing a secret love note.
6. **"Little Things That Make You Special" Cards:** 3 interactive cards with hover lift, click expansion, and unique illustrations.
7. **The Grand Finale Gift Box:** Final surprise box with confetti burst and emotional closing message.
8. **Vintage Music Box Synthesizer:** Built with Web Audio API, playing a soothing crystalline chime melody (OFF by default, never autoplays, 100% royalty-free).
9. **Scroll Progress & Navigation Pill:** Quick jump between chapters with real-time reading progress bar.

---

## 🛠️ Tech Stack
- **Framework:** React 18 + Vite + TypeScript
- **Styling:** Tailwind CSS + Custom Coquette Glassmorphism
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Confetti:** canvas-confetti
- **Audio:** Web Audio API (Lullaby Chime Synthesizer)
- **Deployment:** GitHub Pages via GitHub Actions

## 🚀 Local Development

```bash
# Clone the repository
git clone https://github.com/SharvaniLekkala/Vadina-s-Bday.git

# Navigate to project directory
cd Vadina-s-Bday

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
